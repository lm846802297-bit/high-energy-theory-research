# 真实研究任务试点：UV–EFT 硬核导数

语言：简体中文。英文原版：[README.md](README.md)。

本案例使用正在进行的 Higgs-portal / UV–EFT 计算中的一项有限子任务，验证候选研究记录工作流。

## 任务

独立审计混合标量二点函数硬核导数所使用的闭式 Passarino–Veltman 函数及小-\(r=m^2/M^2\) 展开。独立方法使用自适应 Simpson 求积计算相应的 Feynman 参数积分，并在四个小-\(r\) 取值和两个尺度对数取值上与闭式表达式比较。

模型约定参照 [arXiv:2608.27258v1](https://arxiv.org/html/2608.27258v1)，尤其是单态标量展开和类矢量轻子质量矩阵。硬核公式本身转录自工作笔记摘录 `sources/source-excerpt.md`；不能将该公式归因于上述 arXiv 论文。

## 本任务能够支持的结论

- 所列 \(B_0\) 型函数值及其导数，与独立的 Feynman 参数积分在数值上相符。
- 精确导数组合趋近于 \(4/3-2L\)，其第一阶修正为 \(-4r\ln r-16r\)，独立展开得到的第二阶修正为 \(-28r^2\ln r-32r^2\)。
- 检查的二阶展开为
  \[
  4/3-2L-4r\ln r-16r-28r^2\ln r-32r^2+O(r^3\ln r).
  \]
  其残差只在声明的有限网格上进行测试，并未证明对所有 \(r\) 都成立。
- 在 \(\mu=M\) 时，按声明的插入约定，
  \[
  \Pi'_{\rm hard}(0)=-K/(12\pi^2)+O(Kr\ln r).
  \]
- **仅在声明的单算符投影约定下**，系数因子为
  \[
  C_{\Phi D}/\Lambda^2=K/(6\pi^2v_hv_s).
  \]

## 本任务不能支持的结论

本任务没有重新计算完整 UV 图的分子结构，也没有证明图集合完备。它不能在完成 IBP/EOM 基底约化、场重定义和波函数/参数重整化之后，确立唯一的 Wilson 系数。本任务也没有给出任何实验解释或参数空间结论。

## 可复现产物包

运行：

~~~bash
python tests/eval-cases/uv-eFT-hard-derivative-pilot/run_record_chain.py --output-dir /tmp/uv-eFT-hard-derivative-bundle
~~~

产物包包含带版本信息的来源摘录、输入/配置文件、实际执行的代码、候选 Schema、数值输出、逐条记录 JSON、完整记录链 JSON，以及跨记录验证报告。CI 会将其作为 GitHub Actions 工件上传。

执行契约只针对这个有限范围的自动化试点获得批准。Claim 和证据审查状态仍等待人工科学审查。软件测试通过并不构成完整 UV–EFT 匹配问题的物理正确性证明。

## 独立的 Mathematica 验证

来源追溯包还包含 `verify_pv_derivative_mathematica.wl`。该脚本使用 Mathematica 符号积分和级数展开，检查所列 PV 积分及二阶小-\(r\) 表达式。GitHub Actions 不会执行此脚本，也没有将其标记为通过。

该脚本供本地单独运行使用。修改其状态前，应记录 Mathematica 版本和实际输出。可在 Mathematica 前端打开 `.wl` 文件并执行。遇到 FAIL 结果或无法求值的条件等式时，应先审查原因，而不是修改预期值来强行通过。

## 输出目录安全

为 `--output-dir` 指定一个全新的、尚不存在的目标路径。产物包生成器拒绝覆盖任何已存在的路径，也不会递归删除用户指定的目录。如果上一次运行留下了目录，应先检查其内容并选择新路径；只有确认旧目录内容可以丢弃后，才可手动删除。
