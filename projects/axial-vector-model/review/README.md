# Axial-vector model: referee-response review materials

This directory contains three complementary internal research documents. They are not substitutes for the manuscript or the formal response letter.

## Document roles and precedence

1. **`research-handbook.md` — Researcher-facing working manual.** The detailed source for physical reasoning, assumptions, calculation procedures, applicability conditions, evidence requirements, and outstanding research tasks. It is not the formal response to the referee.
2. **`manuscript-diff-v2.3.md` — Proposed manuscript changes and task mapping.** Maps referee points to planned changes and research work packages. A proposed diff is not proof that the manuscript source has been changed or that a calculation is complete.
3. **`consistency-audit.md` — Cross-document audit snapshot.** Records conflicts found when comparing the current formal response letter, Diff v2.2, the researcher handbook, and the available v6 manuscript PDF. It explains what must be reconciled before submission.

## Authoritative research artifacts

- **Manuscript:** `axial_vector_model_building-v6.pdf` is the manuscript PDF that was available during this audit. It is not a revised PDF containing the proposed changes.
- **Formal response letter:** `axial_vector_model_building-v6_审稿回复信_正式回复_无占位符_2026-10-23.tex` is maintained separately. This directory does not duplicate it.
- **Research status:** An item is complete only when the underlying calculation or source check is supported by evidence, the manuscript has been updated where required, and the response letter states no more than that evidence supports.

## Important status rule

The three files document analysis and proposed work. Their upload or review does **not** mean the outstanding portal-loop, PMNS, UV–EFT truncation, finite-VLL/kinetic-mixing, or stellar-cooling tasks have been completed. Do not merge a “planned” change into a claim that the revised manuscript already contains it without checking the source and rebuilt PDF.
