# Development task T01 — variable-change Jacobian

Status: development only; may be used to improve the Skill.

## Prompt

Let (m_1,m_2>0), and define (s=W^2-(m_1+m_2)^2). Consider the Källén function

[
\lambda(W^2,m_1^2,m_2^2)
=W^4+m_1^4+m_2^4-2W^2m_1^2-2W^2m_2^2-2m_1^2m_2^2.
]

1. Express the Källén function in terms of (s,m_1,m_2) and factor it.
2. For the substitution (s=\Delta u^2), (0\leq u\leq1), derive the complete Jacobian.
3. State how omitting any constant factor in this Jacobian affects an absolute integral and a unit-area normalized distribution.
4. Check mass dimensions.

## Required output

A derivation with explicit assumptions, the transformed measure, a dimensional check, and one independent algebraic or numerical check. Do not assume that normalized-shape agreement validates an absolute rate.
